Кнопка КП ЧЕТС

Встанови сайт як кнопку/додаток на телефон або компʼютер, щоб відкривати графік одним натисканням.

На iPhone треба натиснути стандартну кнопку Safari внизу екрана — квадрат зі стрілкою вгору. Потім прокрути список дій вниз і обери На экран «Домой» / На Початковий екран.
Відкрити графік зараз
iPhone / Safari: натисни нижню кнопку Safari — квадрат зі стрілкою вгору → На экран «Домой» / На Початковий екран → Додати.
Android / Chrome: натисни верхню кнопку Встановити кнопку на компʼютер / телефон, або меню ⋮ справа зверху → Додати на головний екран / Встановити додаток.
Windows / компʼютер: натисни верхню кнопку Встановити кнопку на компʼютер / телефон. Chrome або Edge відкриє стандартне вікно Встановити додаток. Якщо вікно не зʼявилось: меню ⋮ справа зверху → Зберегти й поділитися / Програми → Встановити цей сайт як програму.
Назва кнопки: залиш КП ЧЕТС. Іконка буде біла з чорним тролейбусом.
